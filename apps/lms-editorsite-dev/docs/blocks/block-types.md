*NB: 'Blocks' in this document refer to UI elements in the content canvas that will be converted to JSON blocks*
# Block types

- Editors will be able choose from an array of UI block types form the left-hand block palette.
- Blocks will be grouped by type

## 1. Text

1. Paragraph
     - Available properties:
        - Alignment
            - Centre, left, right
        - Weight
            - bold, light, normal
        - Italic
            - default is no
        - Add link
            - select to add URL
            - check box to open in new tab

![Paragraph properties](images/paragraph-props.png)

2. Heading
     - Available properties:
        - H1, H2, H3...
        - Alignment
            - Centre, left, right
        - Weight
            - bold, light, normal
        - Italic
            - default is no
        - Add link
            - select to add URL
            - check box to open in new tab
3. Numberered list
4. Bulleted list
5. Code
    - Embed code sample for copying
        - Available properties
            - Language
            - Number lines
                - Default is yes
            - Copy code to clipboard
6. Detail
