# Templates

The editor app will have pre-configured layouts for pages and posts. The purpose of these templates is to help ensure that content renders consistently in all sites, regardless of editor

## Content types

Content types are determined by the shared characteristics of a page or post. In this instance, these shared charateristics will be driven by delivery method, i.e., site to be published on, and format, e.g., call to action, knowledge article, page, post, etc.

## Page layouts

The purpse of pages is to render content that is fairly static and mostly for public consumption. Pages fall into the below categories:

1. Landing page
    - FSE experience (single column)
    - Content width defaults to 100vw but can be changed in the properties drawer
2. Content page
    - FSE experience option
    - Left-hand sidebar option
    - Right-hand sidebar otpion
3. Search results
    - FSE experience
    - Has hard coded components
        - Only to be used for search results

### Posts

The purpose of posts is to render content that is regularly updated and has additonal metadata for filtering and search. For the PoC, there will only be one template for posts. 

### Template selection

When a content editor creates new content, they can choose from 'New page' or 'New post'.

If a new page is chosen, they can choose from a gallery of templates
   - Each template in the gallery has a brief description to help them choose the right one
